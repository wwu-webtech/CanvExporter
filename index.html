CanvExporter

Get your Canvas course content out of Canvas and into files you can actually open, read, and print. No importing back into an LMS, no wrangling XML.

Built by a Canvas administrator after the May 2026 Instructure breach, when a lot of us learned the hard way that a course export hands you an .imscc file you can't read without Canvas. There are two versions. Pick the one that fits you.

I teach. I want my own course content. Beta

A button you drag to your bookmarks bar. No install, no account, no access token. Click it inside any Canvas course and it saves your course as readable Word documents and spreadsheets.

Get the teacher version

I'm an admin. I want the full tool.

A Python tool that runs with a Canvas API token and pulls complete course content, including uploaded files, into an organized folder. Built for records requests, departmental work, and jobs at scale.

Get the admin version

What's the difference?

FeatureTeacher versionAdmin version
Who runs itAny teacher, in their own courseAn admin with an API token
InstallDrag a button to your bookmarks barPython and a few libraries
Access tokenNot neededNeeded
What it pullsContent you authored: pages, assignments, quizzes, discussions, rubricsEverything, including uploaded files
Output.docx and .csv in one .zip.docx and .csv, organized folders
StatusBetaReleased

Both do the same core job: turn Canvas course content into readable documents. The teacher version trades completeness for zero-friction access. The admin version trades convenience for a token and pulls the whole course.

A note on files

For downloading a course's uploaded files in bulk (PDFs, slide decks, images), Canvas already has you covered. In the course Files list, select all and click Download, and Canvas hands you a zip. The teacher version focuses on the authored content Canvas won't give you in readable form. The admin version pulls files too, because the API token makes it possible.
